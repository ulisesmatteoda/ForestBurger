# ForestBurger

Trabajo Práctico 1 — Programación Web — UNICEN.

## Cómo ejecutar

1. Clonar el repositorio y posicionarse en la branch `tp1`:

```bash
git clone https://github.com/ulisesmatteoda/ForestBurger.git
cd ForestBurger
git checkout tp1
```

2. Ejecutar el servidor:

```bash
go run .
```

3. Abrir en el navegador:

```
http://localhost:8080
```

Para detener el servidor: `Ctrl + C` en la terminal.
